## 🔧 Troubleshooting

Encountering an issue? Most problems have quick fixes. Check these common solutions:

### ❌ "Windows protected your PC" warning
- Click **"More info"** → **"Run anyway"**. This appears because the app isn’t code-signed, but it’s safe to use.

### ❌ App won’t start
- Make sure you **extracted the .zip fully** — don’t run the .exe from inside the zip.
- Right-click `alysse-executor.exe` → **"Run as administrator"** if you see permission errors.
- Check that your antivirus isn’t blocking the file. Temporarily disable it, run the app, then re-enable.

### ❌ Scripts not working
- Verify your script syntax — use the built-in **"Syntax Check"** button.
- Ensure you’re running the correct script type (e.g., `.lua` for Lua scripts).
- Restart the app after making changes to the script folder.

### ❌ App freezes or crashes
- Close other heavy programs — alysse-executor is lightweight but needs some RAM.
- Update to the latest version by re-downloading the zip.
- Delete the `settings.ini` file in the app folder (this resets settings to default).

If none of these help, see the **Support** section below.
